# AI service boundary

The FastAPI service is internal-only. Neither browser nor Caddy routes to it. The Go worker reads report media from private MinIO and sends bounded base64 image bytes, content type, report ID, and media ID to `POST /analyze/media`; arbitrary URLs and credentials are not accepted. Images are limited to 5 MiB, supported types are JPEG/PNG/WebP, and validation errors do not echo private media.

No inference model is bundled or configured by default. Python returns `503 MODEL_UNAVAILABLE`, not a synthetic prediction. A model adapter must return validated estimates, model/version, inference duration, an explicit non-mock flag, and limitations. Go rejects missing/non-false mock flags and mock model names. Test providers exist only in tests; they are not evidence of live inference.

Migration 16 adds jobs versioned by media ID and report update time, and private `ai_evidence`. Current PENDING and VERIFIED report snapshots can receive jobs; edits and additional media do not permanently strand analysis behind older evidence. Jobs use bounded attempts, leases, and retry scheduling; a failed analysis never becomes a successful result. Exhausted jobs remain visibly FAILED in the database and require an operator-controlled requeue after resolving the dependency; no public retry endpoint is provided. Each worker batch has a bounded context and uses a separate loop from ingestion and alert evaluation. The Go client refuses redirects so private image bytes cannot be forwarded to another service.

ADMIN reads and review operations are under `/api/v1/admin/ai-evidence`. Review requires a currently enabled ADMIN and disallows self-review and repeated/conflicting decisions. Verification refuses stale report snapshots; private stale evidence can still be rejected. Verification inserts canonical observations and an audit record transactionally. A road estimate requires an explicit road ID; no route or road association is fabricated. Approved observations retain `AI` provenance, source report time, confidence, and private evidence lineage. Rejected evidence is not published. Community report moderation remains a separate decision.

Before enabling a genuine model, configure and verify bounded inference execution inside Python. A Go request timeout bounds the caller's wait but does not terminate a synchronous Python model computation.

`GET /health` describes process liveness only, not model readiness or accuracy. No model download, CCTV integration, or live provider is introduced by this change. See `api-coverage.md` for acceptance criteria and verification limits.
